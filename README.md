# DuoSeat

برنامج خفيف لويندوز يشبه فكرة Aster Multiseat: **محطتان (مستخدمان) على كمبيوتر واحد**، كل محطة لها شاشة ولوحة مفاتيح وماوس.

> ⚠️ **نسخة تجريبية 0.1.** الكود لم يُختبر على أجهزة حقيقية بعد. جرّبه على جهاز تجارب أولاً.

*A lightweight Windows tool in the spirit of Aster Multiseat: two stations on one PC. Experimental v0.1, untested on real hardware.*

## الفكرة

- **المحطة 1:** سطح المكتب العادي على الشاشة الأولى.
- **المحطة 2:** جلسة Remote Desktop محلية (loopback) لمستخدم ويندوز مختلف، تظهر ملء الشاشة على الشاشة الثانية.
- **توزيع الأجهزة:** البرنامج يعرف أي لوحة مفاتيح/ماوس مصدر كل ضغطة (Raw Input)، ويحجب الإدخال الأصلي، ثم يعيد إرساله للمحطة الصحيحة (سطح المكتب أو نافذة RDP).

## ⚠️ الشرط الأهم: الجلسات المتزامنة

ويندوز **Home/Pro/Enterprise** (نسخ العميل) يسمح بجلسة تفاعلية **واحدة** فقط. اتصال المحطة 2 سيفصل المستخدم الحالي.
لتعمل المحطتان معاً تحتاج **Windows Server** مع دور **Remote Desktop Services** (ومعه التراخيص المناسبة).
البرنامج لا يعدّل ملفات النظام ولا يتجاوز قيود الترخيص. هو يعرض في أعلى النافذة هل نسختك تدعم ذلك.

## المتطلبات

- Windows 10/11 أو Server، 64-bit، وصلاحيات Administrator.
- شاشتان، ولوحتا مفاتيح، وماوسان.
- ملف `DuoSeat.exe` يحتاج [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). أما `DuoSeat-selfcontained.exe` فلا يحتاج تثبيت شيء (حجمه أكبر).

## الاستخدام (الواجهة الجديدة v0.2)

الواجهة بثلاثة تبويبات: **General Settings** و **Workplaces** و **About**.

1. **General Settings:** اكتب اسم مستخدم وكلمة مرور للمحطة 2، ثم اضغط *Prepare system* (يفعّل RDP، قاعدة جدار حماية loopback فقط، وينشئ المستخدم). بعدها *Launch workplace 2 session*.
2. **Workplaces:** عمود **System** على اليسار يعرض الأجهزة غير الموزعة (تعمل مع المحطة 1). **اسحب** لوحة المفاتيح والماوس الخاصين بالمحطة 2 إلى عمود **Workplace 2** (أو كليك يمين ← *Move to...*). تحريك أي جهاز يضيء إطاره البرتقالي لتعرف أيهما هو.
3. اضغط على صورة الشاشة داخل كل محطة (أو زر ≡) لاختيار **Display** الخاص بها.
4. اضغط **Start** في الشريط السفلي لبدء التوزيع.

لمبة كل محطة: 🟢 تعمل، 🟠 جاهزة/متوقفة، 🔴 مشكلة (مثلاً نافذة جلسة المحطة 2 غير موجودة أو لا أجهزة لها).

**إيقاف طارئ:** `Ctrl + Alt + F12`. وإغلاق البرنامج أو انهياره يفكّ الـ hooks تلقائياً.

الإعدادات في `%AppData%\DuoSeat\config.json`. الأجهزة تُعرَّف بمسارها وقد يتغير لو نقلتها لمنفذ USB آخر.

## حدود النسخة الحالية

- محطتان فقط.
- الكتابة المتزامنة من المحطتين في نفس اللحظة غير سلسة (التركيز ينتقل بين النافذتين، وحالة Shift/Ctrl مشتركة).
- **لا يوجد درايفر كيرنال.** التوزيع يتم في user-mode (Raw Input + hooks)، لذلك مؤشر الماوس الحقيقي واحد ويقفز بين الشاشتين. مؤشران مستقلان تماماً يحتاجان درايفر نواة موقّعاً (WDK + شهادة توقيع)، وهو غير مضمّن ولم يُختبر.
- `Ctrl+Alt+Del` و Pause/Break لا تُمرَّر. الصوت والطابعات والـ USB ليست موزعة.
- لا يعمل مع أجهزة اللمس/القلم كمحطة منفصلة.
- ألعاب ملء الشاشة وبرامج الحماية قد تتعارض مع الـ hooks.

## البناء

الأسهل: ارفع المجلد على GitHub، وسيبني **GitHub Actions** ملفي exe تلقائياً (تبويب Actions ← آخر تشغيل ← Artifacts). ولو أنشأت tag مثل `v0.1.0` يُرفقان في صفحة Releases.

أو يدوياً (يحتاج .NET 8 SDK):

```
dotnet publish src/DuoSeat/DuoSeat.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```
